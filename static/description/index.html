Workflow Inside Odoo

  1. Open any Product Form and click "✨ AI Photo Editor" or the smart button.
  2. Upload raw photography or work directly with the product's existing image.
  3. Select background style (Pure White, Studio Grey, Soft Shadow, Wood Desk, Marble, or Gradient).
  4. Click "Generate Preview" to view real-time before/after results without saving.
  5. Click "Apply to Product" to immediately update image_1920 for eCommerce.
  6. For large catalogs, select multiple products in the list view and choose "Bulk AI Photo Optimization" to run via cron!

REST API Endpoints

POST /api/v1/photo_editor/process - Upload raw photo & get optimized result
GET /api/v1/photo_editor/presets - Available presets and supported dimensions
POST /api/v1/photo_editor/batch - Enqueue batch processing for product IDs
GET /api/v1/photo_editor/status/<job_id> - Inspect status of async jobs
